### Schema strip (`schema_strip.py`)
- Sits between the ask bar and the chat, always visible
- Each column chip shows name + type badge
- When a query is active, touched columns light up with colour-coded badges: WHERE (orange), SEL (blue), GRP (purple), SUM/COUNT/AVG/MIN/MAX (green), SORT (teal)
- Multi-table datasets group chips by table name
- Right-edge legend shows active operations

### SQL panel sync (two root causes fixed)
1. **Raw SQL quick queries**: `_raw_sql_lock` flag prevents `composer._refresh_sql()` from overwriting externally-set SQL on every render
2. **NL Ask**: `_sync_composer_widgets(model)` sets widget session-state keys (select_multiselect, group_by_multiselect, limit_input) before rerun so stale widget state can't overwrite the new model

### Workflow now
- Plain Ask → SQL goes to SQL panel for review → user clicks Explain or Run
- Ask + Analyze → auto-executes and shows insights in chat
- Quick queries → SQL goes to SQL panel → user clicks Explain or Run

## Recommended next task: design / layout round

**Goal**: fit everything on one screen, no scrolling needed.

**Proposed layout**:
```
┌─────────────────────────────────────────────────────────────┐
│  Header (topbar)                                            │
├─────────────────────────────────────────────────────────────┤
│  Ask bar + schema strip                                     │
├──────────────────────────┬──────────────────────────────────┤
│  Chat (scrollable)       │  SQL panel + Explain / Run       │
│                          ├──────────────────────────────────┤
│  Follow-up buttons       │  Results table / chart           │
└──────────────────────────┴──────────────────────────────────┘
```

- Left column = conversation (chat + follow-ups)
- Right column = SQL preview (top) + results (bottom), both fixed height
- Quick queries could be a collapsible strip inside the ask row
- Composer could live as a tab or expand on demand rather than always-open

Key Streamlit constraints to keep in mind:
- `st.container(height=N)` for fixed-height scrollable areas
- Column widths via `st.columns([ratio, ratio])`
- Streamlit re-renders the whole page on every interaction — layout must be stable
