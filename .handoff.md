## Known issues
1. **NL Ask on supply chain demo only queries the primary table** (`products`).
   Cross-table JOINs need the Quick Query buttons. Multi-table NL support would
   require passing `tables_schema` with table names to the LLM.
2. **Heuristic fast-path uses flat schema** in multi-table mode — could still
   produce "no such table: data" if heuristic confidence threshold is met.
   Low priority; threshold is high enough that it rarely triggers.
3. **Follow-up chip buttons** render as full-width Streamlit buttons, not styled
   chips. Original chip CSS styling is unused now.
4. **Version string** in `app.py` status bar still shows `v0.6 · Phase 4`.
