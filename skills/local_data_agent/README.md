# Local Data Agent Skill Pack

This skill pack is for the tri-arm open-data benchmark:

- SQL arm: NL -> SQL path
- Python arm: deterministic pandas operations
- Skills arm: skill-guided planning + deterministic execution

The `local_v1` profile is intentionally local-only and dependency-light.
It maps common analytics intents to deterministic operation IDs used by
`eval/open_data_tri_arm_eval.py`.
